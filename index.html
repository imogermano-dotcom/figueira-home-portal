⚙️ Configuração necessária

Para ligar ao META Ads é preciso adicionar o teu access token como secret no Supabase:

  1. Vai ao Meta Graph API Explorer e gera um token com permissão ads_read
  2. Acede ao Supabase → Settings → Edge Functions → Secrets
  3. Adiciona um secret: META_ACCESS_TOKEN = o teu token
  4. Clica "Carregar" aqui novamente

💡 Para um token de longa duração usa o Access Token Tool e converte para long-lived token (60 dias).
